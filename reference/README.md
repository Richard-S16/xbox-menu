# Original Xbox dashboard references

Start with the released dashboard captures. The Home screenshots show the later dashboard with Xbox Live. The launch-era menu covered Memory, Music, and Settings. The Insignia screenshots show the Xbox Live interface with a modern replacement service. The Clock image is a photo of a display.

Use the two contact sheets for an overview, then open the individual images to inspect text and focus states. Study movement, menu timing, and idle animation in the videos.

For the Tauri app, use these references to study controller navigation, focus and back behavior, and animated depth. Build an original layout, artwork, typography, and sound inspired by the era.
